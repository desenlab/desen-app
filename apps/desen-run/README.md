# DESEN Developer Platform (`desen.run`)

The future developer and integration site for versioned protocol snapshots, SDK guides, API
reference, conformance results, compatibility, and Desen App-independent integration
documentation. It is an open DESEN ecosystem surface, not a second authoring product.

Frozen protocol snapshots published here are checksum-verified mirrors. The site must not rewrite
their canonical schema identifiers or present informative SDK guidance as normative protocol
text.

## Status

Structure reserved. Implementation begins only at its tracked milestone gate.
