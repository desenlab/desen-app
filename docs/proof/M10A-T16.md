## Boundary

T16 adds the App-owned design-time surface for named component variants and declared visual
states. The boundary uses the existing Editor Core ordered-variant commands and the frozen DESEN
0.1.0 `variants` shape. A named preset is recorded as an inert, versioned extension marker plus a
declared primitive state-axis predicate. Variant edits can change only declared style leaves;
children, slots, behavior wiring and arbitrary predicates are never accepted by this surface.

The Inspector now exposes a `Variants` view beside the existing property, Style, State and Actions
views. The Style view exposes declared visual states and named variant layers. State and variant
layers can be promoted into a transient preview document for the canvas; the authored Source and
its conditions remain unchanged until an ordinary Save source operation.
