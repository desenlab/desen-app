## One normal visible product

The [runbook](../plan/DEMO-RUNBOOK.md) starts the ordinary App on 127.0.0.1:5173 through
`pnpm demo:reset`. The fixed private demo store begins empty. A person creates the Flow project,
authors both surfaces, connects inputs, an operation, its success navigation and a conditional
Alert through visible controls, then saves and publishes that exact authored Source. Neither the
browser nor the launcher inserts a prepared positive Source or handwritten managed screen.
`pnpm demo` resumes the same store; a reset retains exactly one previous generation. Existing
ordinary designer projects are not reset. No additional development checkout is required.

Trusted composition supplies the installed Flow profile with the same fixed publication port as
Account. The independent host admits only these two reviewed document profiles and their registered
routes. An authored result alias is validated rather than inferred from a literal `signIn` name.
The optional local sign-in endpoint is disabled by default and enabled only by trusted launcher
configuration. Its test-account decision is shared with App Integration; this is not production
identity or a general-purpose backend connection editor. Runtime Core is unchanged.
