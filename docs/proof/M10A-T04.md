## Delivered boundary

`@desen/design-system-release` is a private, platform-neutral package that turns an admitted
design-system input into one detached, recursively immutable, content-addressed release. The
release manifest is finite and includes token-source JSON, font/icon/image bytes, and inert recipe
JSON. Each dependency has an exact SHA-256 digest and byte count; the aggregate release digest is
derived only from that manifest.

The host-profile reference names one exact release digest. The release-store port exposes only exact
digest reads and atomic puts; it intentionally has no mutable `latest` lookup. A stored release is
re-verified before use, and a missing, mismatched, or tampered snapshot fails closed.

## Executed evidence

The proof executes the built public package root. Equal inputs produce equal release identity; a
changed production asset produces a new identity. Asset bytes are copied and frozen, token and
recipe documents are re-admitted, malformed or missing dependencies are rejected, and an
interrupted write can be retried without selecting another release. The verifier performs no
network access, starts no child process, and writes no workspace files; only the generator writes
the artifact through the shared same-directory atomic writer.

Authority-bearing keys are rejected after normalization in both recipe documents and every level
of an admitted token document, including preserved DTCG `$extensions` metadata. Credentials,
endpoint selectors, loaders, and executable hooks therefore cannot become hidden release input.
