## Delivered boundary

T18 adds a local-first library-management view to the existing Design System area. Each installed
release remains pinned to its exact package identity (`id`, version, target and package digest),
and the view derives usage from saved Source references across inspected local projects. It shows
release metadata, component lifecycle/deprecation and replacement guidance, and a deterministic
reverse usage index for impact review.

Release changes are compared by exact component contract and lifecycle metadata. The comparison
reports added, removed, changed, deprecated and replacement entries, affected Source references,
and an explicit compatible/incompatible result. Adoption is a review-required, non-mutating plan:
rejecting an incompatible or unwanted candidate leaves the prior release selected; accepting a
compatible reviewed plan selects the exact candidate; restore returns the exact prior identity.
There is no implicit latest pointer or unannounced propagation into saved or published designs.

Malformed Catalog/library metadata, package digest mismatches, duplicate identities, invalid
projects and unverifiable Source references fail closed. All projections are immutable and local;
organization identity, multiplayer collaboration, remote package hosting and authenticated team
ownership remain outside this task.
