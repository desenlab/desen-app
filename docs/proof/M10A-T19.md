## Delivered boundary

T19 adds a separate Connections workspace inside the existing Desen authoring surface. Designers can
inspect node-linked connection intents, keep incomplete intents as durable inert drafts, reopen them,
apply valid candidates, or discard drafts. Malformed candidates, stale targets, invalid source
references and unsupported actions fail closed.

Connections are intentionally not behavior wiring: applying a draft only admits a valid DESEN Source
connection record, while event/action execution, navigation, runtime activation, Publisher mutation
and release behavior remain outside this boundary for later M10A tasks.

## Explicit non-claims

T19 does not add event/action wiring, navigation execution, Runtime or Publisher authority, release
activation, remote collaboration, arbitrary code execution, G10A or M11 authority. Those remain owned
by later M10A tasks and the frozen DESEN protocol/Core boundaries.
