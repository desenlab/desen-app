# M10A-T07 — Selection and numeric-control starter capabilities

**Status:** `IN_PROGRESS` — local evidence is recorded; exact-head hosted Quality gate and
fresh-`main` closure are still required.

## Delivered local boundary

T07 extends the private `@desen/starter-catalog-web` Web–React starter Catalog to
`run.desen.starter.web@0.4.0#web-react`, with 20 bounded capabilities. It extends the existing
Select implementation and adds Combobox, Tabs, Slider, and NumberField. The public root remains
inert Catalog/types/templates; the explicit `./react-adapters` subpath supplies the same static
adapter registry to isolated authoring and independent-host proof graphs.

Selection data is closed and data-only: options have stable identities, Select accepts its legacy
`value` spelling or `id` and normalizes the result, and Combobox admits only finite `contains` or
`startsWith` filtering. Tabs requires an ordered public `panels` slot. Slider and NumberField admit
finite values between -100000 and 100000 with a positive finite step. Duplicate option IDs,
non-finite values, malformed runtime event payloads, functions used as renderers or filters,
private selectors, arbitrary DOM props, executable markup, and remote media are rejected rather
than ignored.
