**Status:** `DONE` — exact-head hosted and fresh-`main` closure receipts are recorded below.

## Delivered boundary

T05 extends the private `@desen/starter-catalog-web` Web–React starter Catalog with Box, Stack,
Grid, Text, Heading, Image, Icon, and Separator. It preserves the existing Button, Select, and
Dialog slice rather than replacing it. The public root remains inert Catalog/types/templates; the
explicit `./react-adapters` subpath supplies the static runtime registry used by both proof graphs.
The expanded current Catalog is `run.desen.starter.web@0.2.0#web-react`; its predecessor's
`0.1.0` receipt remains historical rather than being rewritten under the same Source-facing version.

The layout contracts admit one ordered managed default slot with 1–100 children, finite Stack
direction/wrap, Grid columns 1–12, and explicit LTR/RTL direction. Their root style parts have
closed schemas for bounded logical spacing, sizing, alignment, distribution, overflow, colors,
borders, opacity, and `fill`/`hug` sizing where declared. Text and Heading admit bounded inert
strings; Heading has level 1–6. Image accepts only the named in-package `neutral-horizon` or
`neutral-grid` source; Icon accepts only its closed name set and a label/decorative contract;
Separator has a finite orientation. Image deliberately does not accept a foreground `color`: its
trusted SVG data source is rendered as an image, so accepting a color it cannot apply would be a
silent no-op. Icon retains its finite foreground color control because it is rendered as trusted
inline SVG.

The scope is deliberately bounded: Source cannot select a CSS selector, DOM target, callback,
renderer, external image URL, SVG/HTML markup, font, or arbitrary style property. Unknown style
properties, private selectors, invalid dimensions, executable content, and remote media are
rejected rather than ignored. Layout children remain admitted Source nodes and preserve their
declared slot structure. Accepted borders project a visible solid border; Separator exposes its
visible line through `backgroundColor` rather than admitting a semantically ineffective border.
The vertical Separator has a visible 24px minimum default height even in an ordinary root or
vertical Stack, while retaining its finite explicit dimension overrides.
Column-flow Grid calculates finite explicit rows from its managed child count, so its declared
column count cannot spill into implicit extra columns.
