## Delivered local boundary

T06 extends the private `@desen/starter-catalog-web` Web–React starter Catalog to
`run.desen.starter.web@0.3.0#web-react`. It adds TextField, TextArea, Checkbox, RadioGroup, and
Switch, while reviewing and retaining the existing Button rather than creating another Button
implementation. The public root remains inert Catalog/types/templates; the explicit
`./react-adapters` subpath supplies the same static registry to isolated authoring and independent
host graphs.

The form contracts admit accessible label/help/error composition, keyboard focus, and only bounded
controlled event payloads: `change:{value:string}` for TextField/TextArea/RadioGroup and
`change:{checked:boolean}` for Checkbox/Switch. Invalid form values, malformed event payloads,
private selectors, arbitrary DOM props, callbacks, executable markup, and remote media are rejected
rather than ignored. Styling projects declared appearance without removing native or ARIA
label/described-message relationships.

This is a starter-Catalog and isolated-harness slice. It does not add normal-App design editing,
draft-library persistence, Publisher authority, Runtime activation, business actions, application
state wiring, arbitrary CSS/DOM access, package publication, production deployment, G10A, or M11.
