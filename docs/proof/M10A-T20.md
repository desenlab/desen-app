## Delivered boundary

T20 adds a visual behavior panel to the existing Desen Connections workspace. Designers can use
typed controls for local state and initial values, declared events, closed actions, conditions and
navigation after the visual surface has been authored. The controls edit the same managed Source
and aggregate history authority as Design; undo/redo therefore preserves the authored appearance
and behavior as one bounded project transaction.

Saved connection-intent notes remain durable inert metadata. A missing or incomplete intent does
not create a fake handler, and malformed, dangling or type-incompatible behavior references are
rejected by the existing fail-closed authoring boundary. No raw JSON is required in the normal
workflow.
