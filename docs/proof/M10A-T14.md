## Delivered boundary

T14 adds a platform-neutral, bounded history and reuse boundary to `@desen/editor-core`, then wires
it into the normal Desen App authoring surface. Undo and redo retain independently admitted,
recursively immutable Source snapshots. A new authored edit clears redo; history defaults to 100
entries and admits an explicit limit only from 1 through 512.

Copy captures one or more non-root nodes from one admitted surface into an App-owned in-memory
payload. The clipboard survives admitted-surface remounts inside the same project, but an opaque
workspace-profile or project change clears it. Duplicate uses only the payload produced by that
exact attempt, so a rejected current selection cannot reuse an older clipboard. Multi-selection is
projected into Source order before capture and insertion, independent of click order. Paste can
target another admitted surface, but the App commits the candidate only after current Catalog
validation and preview preparation. Existing generation-fenced persistence remains the only save
boundary.

Identity and binding remapping is two-pass: all selected roots, descendants and behaviors receive
fresh IDs before references are rewritten. Referenced state and transitive resource dependencies
are normally copied under fresh dot-safe `-copy` roots; if an admitted boundary-length action path
leaves no suffix budget, a deterministic compact reference-safe root is used. Selected
`operation.invoke` aliases also receive fresh lifecycle identities. The closed-schema walker
rewrites ValueSpec and predicate references,
state/resource actions, nested `operation.invoke` success/failure actions, and selected
`component.command.target` links. Non-reference values, state schemas/initial values, and opaque
`extensions` remain exact. Missing dependencies, component command targets outside the captured
identity closure, external operation aliases, conflicting alias ownership, or incomplete remapping
reject the complete transfer. Allocated identities remain
inside the 128-character protocol ceiling, including collision suffixes and state roots used by
boundary-length action paths.

Clipboard selection is limited to 256 roots, 8 MiB of canonical payload and Source depth 64. The
boundary rejects foreign payload copies, ambiguous/repeated identities, ancestor-plus-descendant
selection, invalid targets, accessors and throwing reflection wrappers with frozen diagnostics and
without a partial document. History construction and record operations independently re-admit even
runtime-cast mutable inputs, and every transition requires a Core-created history authority, so a
forged mutable snapshot or limit cannot enter the chain. Clipboard capture, placement lookup and
paste also re-admit hostile runtime-cast Source inputs before reading them.

T14 does not add OS clipboard interchange, masters/instances, variants, executable clipboard data,
Runtime or Publisher authority, protocol changes, G10A closure, or M11 readiness.
