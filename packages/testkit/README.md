# @desen/testkit

## Responsibility

Synthetic fixtures, host fakes, conformance helpers, trace assertions, and proof artifact utilities.

## Explicit non-responsibilities

No production runtime dependency on this package and no real credentials or personal data.

## Status

Scaffolded and private. Functional APIs will be added only by their tracked implementation tasks.

## Protocol and target support

- Protocol baseline: DESEN 0.1.0
- Initial target: platform-neutral unless explicitly adapted

## Quality

Use the root workspace quality gate: `pnpm check`.
